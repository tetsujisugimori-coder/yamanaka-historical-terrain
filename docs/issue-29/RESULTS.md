# Issue #29: 西木戸口の景観連続性

## 提出時の判定

**総合 PARTIAL・景観限定受入 PENDING・マージ NO。** 正式CI、別担当による比較確認、新規証拠の保存後検証は独立した項目。正式結果の現行台帳は本Draft PR本文とその追補。Stage 3-B HOLDは変更しない。

## 実装と範囲

- 既存西方パッチとI側の地表は、0.5m間隔の境界940点で両方の実GLBを別の三角形補間器から照合し、欠測なく既存1mm数値閾値内で一致。**実際の穴を埋める修正ではない。** 内部にはC地表の層の差があり、その再造形や精度の確証は対象外。
- 同じ地表座標に同じD色を置く22m漸減帯で、既存パッチと周囲の素材色だけをつなぐ。内側は赤土・草・踏み道を保ちつつ局所的な斜面明暗を付ける。門の木材色、既存の背景とfogの色を小幅補正する。距離閾値・光の本数・影解像度・影方式・植生配置は変更しない。
- 仕上げONのC+Dかつ西方の表面が存在するときに新規処理を適用。現況A、Cのみ、仕上げOFFへの切替で原表示に復帰する。地形・施設・植生の座標、既存原GLBと編集原本、歩行判定/断面式は変更しない。史実確証や現地の通行可否を意味しない。
- 長期のGPU/描画時間最適化・LODは対象外。代表条件では描画数・三角形数を比較し、初期表示の壁時計は診断用に記録する。タイミングから高速化を断定しない。

## 検証と証拠の見方

- 新規単体6件（境界色不一致、地表欠測、20mm段差を検出する負対照を含む）。保全を含む既存単体は別集計。両版のビルドは別々の既存ツリーで比較。
- [専用CI](../../.github/workflows/issue29-landscape.yml) は既存main由来の基準版と候補の実ビルドをループバックで比較する。Chromium/WebKit×4幅×通常/軽減の16条件。西木戸口・接続俯瞰・土橋・堀・土塁・遠景を、同じ座標・カメラ・画面寸法で確認し、1280通常、375軽減の代表画像を収録。各条件のA/C断面、木柵5柱、1.7m歩行、ブラウザ相当タッチ、現況A、Cのみ、D仕上げOFF、Reset、エラーと描画量の差を検証する。
- 同じランナーで取得した結果でも、計測用指標と景観の独立目視は別。画像選択は固定、CI失敗や未到達を成功に読み替えない。実機Safari、物理タッチ、実GPU計測、史実の形状・材質はNOT_TESTED。
- 正式原票は専用CIから収録し、必要な新規証拠だけ承認済み経路と照合する。旧原票を再生成・再保全しない。関連通信障害（PR #55）は別Lab Issue #7のPENDINGを維持し、原因調査や閾値変更をしない。
