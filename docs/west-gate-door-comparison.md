# 西木戸口：右門扉の観察と左右比較

## 対象と操作

復元Cで西木戸口の既存観察地点を選択し、西から東を向く。北側が左、南側が右。左右ボタンで各扉全体、同じ部位ボタンで板材・上下横桟・門柱側を観察する。金色の枠はバッチ化前に採録した配信GLBノードのワールド座標の境界箱であり、歴史的な部品境界・接合やZ順を証明しない。描画と衝突に用いる既存のバッチ化済み模型はそのままとし、右は採録した境界箱に注視（板材は代表の板2、柱は中心）、左は既存の注視点を保持する。立ち位置・目線高を変更せず、左右を何度切り替えても観察前の位置・向き・画角へ復帰できる。C模型が利用できないときは旧状態と枠を破棄する。

「左右の構造を比較」で構成、配信ノードの軸平行な扉外形（門柱を除く）、制作寸法、ローカル座標、制作角、共通の支持基準、根拠区分を表示する。左右の共通点は縦板6枚・横桟2本・門柱1本。相違点は北／南の配置、制作角の符号、板群のE座標。左右の板群中心が同じEとは限らず、左右対称だったとする史実の根拠はUNKNOWN。実際の蝶番・仕口・接地・開閉の方向にも踏み込まない。
