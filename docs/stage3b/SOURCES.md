## 地理参照の到達点と保留

p65図3-35について数値座標枠・縮尺・測地方位を確認できず、独立した対応点を確定できなかった。GSI標準地図の同地域(z17)も閲覧し、現況道路・寺社・等高線を補助照合したが、曲輪境界の確定根拠にはしなかった。**対応点0、変換未実施、残差null、精密重畳NOT_COMPLETED**。残差0ではない。PDF刊行年は測量年を証明しない。

既存features.jsonの観察アンカーは明示された概略点で、測量基準点ではない。西ノ丸付近の原図578.4m表記と既存westアンカー550.2mは同一地点だと確認できないため、差を位置誤りや標高誤りと認定していない。自動移動・原図強制フィットをしていない。

## QGIS再現経路（今後の対応点取得後）

1. 既存 `production/yamanaka.qgz` または `production/yamanaka-phase3c.qgz` を複製して開く。前者8レイヤー、後者21レイヤーは今回全有効。原本を上書きしない。
2. 現況DEM、ソースマスク、概略観察点、C/D施設を別レイヤーのまま保持する。QGISプロジェクトCRSはEPSG:6676。
3. 原図は権利確認済みの作業領域だけで地理参照。対応点表に原図ピクセル、対象座標、同一地点根拠、資料頁、現況改変の有無を保存する。名称ラベル中心や概略観察点を測量点と見なさない。
4. 変換モデルに必要な独立点を確保し、検証用点を別に残す。点数、変換式、残差、除外理由、原図線幅と現地位置の不確実性を記録する。適合残差だけで歴史精度を認定しない。
5. 資料ごとに別図形を持つEPSG:6676のGeoPackageを正本とし、Web座標はE−E0、N−N0（3D zは符号反転）、標高基準を別記して生成する。GeoJSONに投影座標を格納する場合はRFC7946のWGS84と誤認しない契約を明記する。
6. 本工程のnull geometryは、根拠を伴う対応点・図形が得られた後にのみ置換する。取得範囲不足と城域境界不明は別判定。

## 境界・名称の注意

指定範囲、歴史城域推定（約20万m²）、現況DEM取得範囲（4km角／1km×1.1km）、詳細C/Dモデル範囲は別物。面積から円・矩形の境界を捏造しない。北条丸→二ノ丸の改称と、古絵図が西ノ丸を二ノ丸と呼ぶ例を混同しない。元西櫓の名称は櫓の確実な存在を証明しない。現代制作状態を1590年当時の未完成記述から推測しない。
