# 第3期G：地形と固定版部品の実寸連携

## 範囲
Fの実XY・面構成を保持して狭域の高さだけ改訂。詳細はproduction/phase3g/README.md。A・旧F・過去証拠は不変。新形状はCであり新しい考古学的寸法を確定しない。D材質は従来の表示切替を維持する。

## 部品契約
castle-3d-partsのmain固定742567b505240934d851c1e2c33a47cc08051470からcatalog/wooden-palisade-v0.jsonを取り込み、SHA256をmanifestへ固定。実行時に外部mainを取得しない。再取込は `node scripts/parts-import.mjs <local-library-clone>`、検査のみは引数なし。

ID wooden-palisade-late-sengoku-v0、0.1.0、5柱・2.0m高・1.2m芯間隔・0.15m角・横木2段。全幅4.95m。Three.js暫定生成で、正式CAD/GLB由来ではない。GLBとそのhashはnull。既存CAD制作の未提出成果を正式配布済みと扱わず、承認待ち操作を迂回しない。

EPSG6676由来のローカルE/N/upをE/up/southへ写像。初期E=-20,N=0、東西向き。パネルで0/45/90度と試験寸法倍率0.5/1/1.5を変更可能。歴史的位置の証明ではない。SRC-0001/L01は文脈参照のみ。未提出OBSのIDを存在する公開根拠として参照しない。

## 接地と衝突
表示する実GLBのworld三角形へ柱芯ごとに下向きrayを投射し、5柱別の基準高を得る。地中埋込0mは接地表示の仮定で史実の根入れではない。各柱は垂直、横木は隣接柱間を傾けて接続。支持面欠落、15度超斜面、全柱間0.4m（誇張2倍時0.8m）超落差は拒否。斜面法線はinverse-transposeでworld空間へ変換する。

鉛直誇張1/2倍では地形支持高だけを更新。部品高/幅は変わらない。変更時は歩行を停止して衝突worldを再構築。部品の実meshを既存三角形障害物判定へ渡す。A/非C/区域外観察では部品を非表示。部品取得/ハッシュ不一致は部品だけ停止し地形展示を継続。

## 制作と検査の区別
FreeCAD→STEP→Blender→GLBの本Gでの正式固定連携は未完了。独立リポジトリIssue3の制作と重複しない。新規CAD正本を山中城へ作らない。QGIS/BlenderのG地形CLI再生成・別プロセス再読込は実行済み、GUI手動操作ではない。

独立レビューの斜面法線P2は実10度×2を旧5.03837度と過小評価し、19.4254度の独自期待値でRED→GREEN。別の定点状態残留は部品選択時にcamera intentを更新して定点を解除する局所修正。原失敗を保持する。
