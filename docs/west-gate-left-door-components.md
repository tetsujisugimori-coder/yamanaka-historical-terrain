# 西木戸口・左門扉の部材別注視（Issue #60）
## 目的
PR #59の定点観察を再利用し、推定C左門扉の板材、上横桟、下横桟、門柱側の取り合いを個別に注視する。
## 根拠と留保
- Blender制作式の gate.door.1.0..5（板6枚）、gate.door.rail.1.0.45 / 1.2.15（上下横桟）、gate.post.1（北門柱）を参照する。
- 板材は代表する1枚を注視。門柱側は北側端板と門柱中心の中間を注視する。部材の描画メッシュ選択や実際の接触点の証明ではない。
- 接合金具・蝶番・軸受・仕口・木目・史実の開き方向は未確定。模型の位置・構造・寸法はC推定と明記し、見えない構造を創作しない。
## 操作
1. 西木戸口の固定観察地点を選び、C復元模型を表示する。
2. 左扉全体、板材、上横桟、下横桟、門柱側を選択。FOVは順に40 / 24 / 22 / 22 / 24度。カメラ位置と目線1.7mは変更しない。
3. 部位を何回変えても開始前の位置・方向・FOVを保持し、戻る操作で一度に復帰する。
4. 地点変更、A現況への切替、Cモデル表示不成立で旧状態破棄。座標不正・支持地表欠損では無変更で拒否。
## 検査と非対象
- Node単体で座標・縦倍率・不正値拒否・Blender式との結合・部位切替と復帰を検証。
- 正式CIのChromium/WebKit各4幅×通常/reduced-motion 16条件で実押下・復帰・表示切替を確認する。実ブラウザ試験は実測までNOT_TESTED。
- 現況A、地形、GLB、EPSG:6676、C/D区分、歩行衝突、断面、史料、原証拠は不変更。
- 実機Safari/VoiceOverと現地照合はNOT_TESTED。Stage 3-B全体HOLD、既知通信問題PENDING。新規原証拠だけ承認範囲で保存し、独立レビュー後に限定マージを別途判断。
