# 第3期F 局所的な実形状改訂

基準 main 8736f32fb188e12b9c908ba3ea328c4a42cc3b40 (PR18統合)、Issue19。

## 範囲と契約
既存A、旧C GLBと編集正本、過去証拠はそのまま保持。新しい phase3f.glb は既存nishinomaruの局所改訂候補、phase3f-inner.glb は既存phase3cの土橋局所改訂候補。施設IDと地理座標/軸/単位の契約を維持する。全城域の一律細分化ではない。編集区域とC推定パラメータは production/phase3f/parameters.json。

三次元の頂点高さ・面の構成を実際に変更し、材質Dと分離。堀周期など旧仮定を検証済史実にしない。新しい史料の位置/寸法/1590年形状の確証はなくUNKNOWNを維持し、Bへ昇格しない。草/赤土の既存D材質は変更していない。共通木造CADの新規正本は作らない。

## 表示・歩行・断面
getModelの復元Cは新版GLB、現況Aは旧castle.glb。既存切出しと施設IDを保ち、同一実三角形から歩行支持高と二つの固定断面を取得する。三角形の高さをmetadataで代用しない。1倍/2倍表示でも人物目線は地表+1.7mで、人物を2倍にしない。堀/土塁・急斜面・段差・欠落・既存木造障害物の保守的制限は維持する。場所間は従来どおり地点移動、史実の経路ではない。

8地点のうち新地形にかかる支持高・見通しtarget高は、新GLBから算出したphase3f.json.stationSupportで既存metadataに局所適用。旧phase3c.jsonは改変しない。ID/座標/有限数を検査し、不一致なら拒否する。

固定28m/30m断面は既存交差関数で新版全GLBから再取得。旧サンプルを正解として流用しない。現況Aは不変。旧版と新版の実三角形から独立に計算した変化量を制作証拠に保存。

## 回帰検査のパス変更
以前のブラウザ受入でnishinomaru.glb / phase3c.glbを正解・404対象・hash対象にしていた箇所は、新しく実際に表示するGLBへ追従させた。チェック内容・閾値を緩和しない。旧版の静的単体と原本検査は旧ファイルに対して維持する。新たな固定断面・歩行支持高・証拠欠落/改変拒否の試験を追加する。

## 操作停止のP3
独立担当が、歩行中の品質変更で入力は停止してもFOV65が残り、明示終了(FOV38)と異なることを再現。停止時にFOV38へ戻す局所修正。品質変更では現在位置を意図的に維持して「この位置で通常観察」と表示し、明示終了は従来どおり俯瞰へ戻す。カメラを不用意にテレポートさせたり新しい操作意図を上書きしない。

## 未検証を区別
実QGIS/Blender CLI/headlessと編集ファイル再読込はGUI手動操作とは区別する。WebKit自動操作は実iPhone Safariでない。実機Safari/VoiceOver/物理タッチ/端末性能はNOT_TESTED。既存タイムアウトは再現しなくてもUNKNOWNを消さない。描画負荷の数値はソフトウェア描画環境の短時間測定でFPS保証ではない。
