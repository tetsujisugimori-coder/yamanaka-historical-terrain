# 第3期E：模型上の城内探索

基準main: 04e7563fcea7e9a67a1a4edf7935ab203294f400（PR16統合）。Issue17。

## 境界と実装
- `src/exploration.js` は表示済み地表の三角形を下向きrayで取得。GLTFのeast/up/southのまま計算し、地理座標のnorthは-z。目線は表示面＋1.7m。2倍誇張時にも目線自体を2倍にしない。
- 移動許可は3つの模型区域の和集合。地域間の空白を接続しない。中心と半径0.28mの8周辺点を検査し、面無し・堀・土塁・38度超斜面・急な高低差は拒否。1回の移動を最大0.12mで分割。人体の厳密な物理シミュレーションではなく保守的な簡易制限。
- 門/柵/建物の表示三角形を包む局所AABBを2m空間グリッドへ登録。バッチ全体の箱で中庭を塞がない。頭上の梁を通す一方、足元＋0.12mから1.7mに交差する部材は拒否。斜材のAABBは実物より広い場合があり、通れる隙間を保守的に閉じることがある。
- 0.7/1.4m毎秒。入力中だけrequestAnimationFrame。処理遅延時のdtは最大50msで、復帰時に飛ばない。低速環境では実時間より移動が遅くなり得る。自動揺れ・慣性・カメラアニメーションはない。
- WASD/方向キー移動、Q/E見回し、1pointerドラッグ見回し、画面ボタンのhold移動。フォーカス喪失、blur、visibilitychange、pointercancel、モード切替で入力所有を解除。フォーム上のキーを歩行に使わない。Escapeと終了ボタンで俯瞰に戻る。
- 8既存地点は指定順に**地点移動**。連続歩行・史実の通路とは表示しない。案内から安全支持のある地点で自由歩行を開始できる。堀端などは開始拒否し、西ノ丸を案内する。
- A/C切替、倍率切替、施設表示切替、品質切替、Resetで歩行を終了。古いframeやpointerupが移動を再開しない。元のcamera-intent処理は既存負対照の契約を保持。

## 精細化と未達
`src/close-detail.js` は独自の決定的128²土粒/木繊維DataTextureを生成する。既存の大域色むらを保ったまま近距離bump/roughnessを重ねるD材質。標準/高品質のみ、軽量では省略。土約16mm/木約8mmのシェーダー上の凹凸で、物理メッシュや考古学的実寸ではない。AとCのみでは解除し、元材質・ジオメトリを保全。

Cの地形再細分化・輪郭変更、門/柱の新しい仕口・接合材、全施設の造形改修は本便では未実装。元GLB・Blender・QGIS正本の変更を避け、歩行と入力整合を優先した。土橋/虎口の急な既存模型勾配により自由に到達できない範囲は案内地点移動を使う。地形の通りやすさを見せかけるため既存模型を書き換えない。

## 史料と制作
既存のsource-model-ledgerとphase3c/phase3d資料を継承。新しい1590年の位置・寸法・構法の証拠は得ていない。Bへ昇格しない。D材質は史実の証明ではない。現況Aと固定2断面の原座標は変更しない。
本便でBlender/QGISによる再制作は実施していない。再生成正本はJSの純粋テクスチャ関数と移動設定。既存production内のBlender/QGIS・GLBはそのまま使用。物理端末のSafari/VoiceOver/タッチ入力はNOT_TESTED。WebKit実行結果と同一視しない。
