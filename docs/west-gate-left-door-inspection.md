# 西木戸口・左扉の固定視点観察（Issue #58）

## 対象
既存の `ic-station-westgate` で実地表＋1.7mの目線を維持し、正面から見て左（北）側に当たる既存C候補扉を見やすくする。左扉の板の中心は `scripts/phase3b-build-blender.py` の `gate.door.1.*` の生成式から求める。門扉の史実位置・寸法・開閉向きは **UNKNOWN** であり、新規の測量や歴史資料による確定は行わない。

## 操作
城内観察から「西木戸口」を選び、「左扉を詳しく見る」を押すと**同じ立ち位置**で左扉のC候補中心へ視線を合わせ、FOV60°から40°へ絞る。既存のドラッグ・矢印キーで見回せる。「元の視点・向きに戻る」で直前のカメラ位置・向き・画角に戻す。地点移動やA現況切替、C模型が利用できなくなったときは古い復帰状態を破棄する。地形・GLB・衝突・歩行判定は一切変更しない。

## 検査と残課題
- Node契約検査：左右関係、著作モデルの座標/板列/寸法との結合、縦倍率の反例、誤入力拒否、観察開始ゲートを確認。
- 必須ブラウザ確認：Chromium/WebKit各4幅×通常/reduced-motionで、西木戸口選択→左扉→元視点復帰。正面・斜めの描画、ボタンの活性・失敗時の無変更、A現況への切替、旧状態破棄、キーボード操作も見る。
- 正式CI、ブラウザ実操作、独立レビュー、正式証拠の再取得・照合は結果を得るまで **NOT_TESTED/PENDING** とする。実機Safari/VoiceOver/現地照合もNOT_TESTED。
- Stage 3-B HOLD、既存通信問題PENDING、main直接変更・自動公開・無承認マージ禁止は継続。

技術的注意：`landscapeModel` は同一ID/材質ごとにメッシュを統合するため、描画時に扉の個々の板を選別できると主張しない。今回の機能は編集元の生成式に基づく**視線の指示**であり、扉の幾何/材質そのものを変更しない。
