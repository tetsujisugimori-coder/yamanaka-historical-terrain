# 第3期C 証拠案内

- native/: 実Blender/QGIS制作と別プロセス再読込。初回過密メッシュの票はinitial-denseに保存し最終版と区別。
- geometry/: 製作者による実GLBの接続・支持・ID分類と負対照。
- preservation.json: PR12マージ済みmainとの既存1263ファイルbyte照合。旧source6レコード保持、追記だけ。
- sections/: 既存固定2断面を別raw GLB oracleと照合。地形正本は変更なし。
- finish/: 共有geometry/UV旧RED、新GREEN、故障再投入拒否。
- browser/: 実装担当の観察・モード・読み込み成功失敗検査。local-blockedの起動失敗はNOT_TESTED。
- appearance/: 同一地点・カメラ・画面サイズの第3期B比較。視覚改善に0画素一致を要求しない。AへのD操作非干渉は既存分離検査の0画素条件を維持。
- performance/: 同一runner・画面・カメラ・品質の起動/操作測定。持続FPSやGPUメモリを推測しない。
- independent/: 史料、3D技術、ブラウザの独立担当。自己テストと明確に区別。

CI実行後の成果物を検証・目視して最終報告へ反映する。ログ保存や画像生成だけをPASSとしない。
