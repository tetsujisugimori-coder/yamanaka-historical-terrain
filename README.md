# 山中城 — 歴史地形図録

国土地理院の現況標高と歴史資料を区別し、山中城と箱根西麓の地形を読む研究用Webプロトタイプです。

**制作中 / 独立レビュー前。公開サイトへのデプロイ、史実の完全復元、攻城戦ゲームは含みません。**

コードと独自教材はMIT。地理院タイル由来データには国土地理院の利用条件と出典表示が必要です。三島市の図面・写真・PDFは再配布しません。

初期実装・再現手順・検証資料は作業ブランチのDraft PRで管理します。
